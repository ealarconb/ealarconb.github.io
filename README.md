# Eduardo Alarcón-Bustamante — academic website

Static website for https://ealarconb.github.io. No installation or build needed.

## Publish
Upload the contents of this folder to the root of the repository (not the folder itself). In Settings → Pages, select Deploy from a branch, main, / (root), then Save.

## Edit
Each section is an HTML file. Shared design: style.css. Replace assets/cv.pdf to update the downloadable CV. The current design intentionally uses no portrait; a new photograph can be added later.

Content migrated from the supplied WordPress export dated 2026-11-12. Only Home, Research, Publications, Outreach and Media, CV and Contact are included. The GitHub profile link in Contact is preserved from the original export (edalarconb); confirm whether it should be replaced with ealarconb.
